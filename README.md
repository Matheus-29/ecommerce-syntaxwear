# SyntaxWear - Tênis e Sneakers Online 👟

Bem-vindo ao repositório da **SyntaxWear**, uma loja virtual moderna e estilosa especializada em tênis e sneakers. Este projeto foi desenvolvido focado em proporcionar uma experiência de compra visualmente atraente e responsiva.

---

## 🚀 Sobre o Projeto

O **SyntaxWear** é um protótipo de e-commerce que apresenta as tendências mais atuais do mercado de calçados. O site conta com uma interface limpa, navegação intuitiva e seções que destacam os produtos de forma dinâmica.

### Principais Funcionalidades:
- **Design Responsivo:** O site se adapta a diferentes tamanhos de tela (desktop e mobile).
- **Menu de Navegação:** Acesso rápido às categorias Masculino, Feminino, Outlet, Sobre e Lojas.
- **Seção Hero:** Um banner principal impactante com chamadas para ação (CTA).
- **Categorias:** Cards interativos para navegar entre os estilos Casual, Esporte, Moderno e Futurista.
- **Grade de Produtos:** Exibição organizada dos modelos em destaque.
- **Newsletter:** Campo para inscrição e recebimento de novidades por e-mail.
- **Rodapé Completo:** Links úteis e integração visual com redes sociais (Instagram, WhatsApp, TikTok, Facebook).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores práticas de desenvolvimento web front-end:

- **HTML5:** Estruturação semântica de todo o conteúdo.
- **CSS3:** Estilização avançada utilizando:
  - **CSS Variables:** Para fácil manutenção de cores e fontes.
  - **Flexbox & CSS Grid:** Para criação de layouts complexos e responsivos.
  - **Componentização:** Organização dos estilos em arquivos separados (header, footer, hero, etc.) para facilitar a leitura.

## 📁 Estrutura de Pastas

```text
/
├── index.html          # Página principal do site
├── css/                # Pasta de estilos
│   ├── base.css        # Estilos base de fontes e elementos
│   ├── reset.css       # Reset para consistência entre navegadores
│   ├── variables.css   # Definição de cores e variáveis globais
│   └── components/     # Estilos específicos de cada seção (Header, Hero, etc.)
├── images/             # Pasta de recursos visuais
│   ├── banners/        # Banners principais
│   ├── icons/          # Ícones de interface e redes sociais
│   ├── logo/           # Logotipo da marca
│   └── products/       # Fotos dos tênis e modelos
└── README.md           # Documentação do projeto
```

## 💻 Como Executar o Projeto

Como este é um projeto front-end estático (HTML e CSS), você não precisa instalar nenhuma dependência complexa.

1.  Faça o download ou clone este repositório.
2.  Navegue até a pasta raiz do projeto.
3.  Abra o arquivo `index.html` em qualquer navegador (Chrome, Firefox, Edge, etc.).
4.  *Dica:* Se você usa o **VS Code**, recomendo utilizar a extensão **Live Server** para ver as alterações em tempo real enquanto edita o código.
